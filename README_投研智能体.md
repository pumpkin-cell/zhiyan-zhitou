## 一、这个赛道要我们干什么（一句话）

企业（达观数据）的痛点不是"再挖几个因子"，而是：**把量化研究员每天大量重复、标准化的工作（读研报 → 复现因子 → 回测验证 → 写报告）自动化成一个"智能体系统"**，让研究员把时间省下来做创造性判断，并把经验沉淀成公司可复用的资产。

命题要求做出 **5 大模块**：

| 模块 | 要做什么 | 我们对应的文件 |
|---|---|---|
| ① 研报复现 | 输入研报，自动理解假设、复现因子、生成因子卡片 | `reproduce_report.py` |
| ② 因子知识沉淀 | 解释因子收益来源、筛选有效因子、识别冗余、入库 | `factor_cards.py` |
| ③ 智能因子组合 | 多因子组合 + 纳入手续费/滑点/仓位等真实约束 | `rotate_backtest_v4.py` |
| ④ 多层次回测 | 样本外 + walk-forward + 压力情景 + 生成式模拟 | `sample_out_validation.py`、`stress_test.py` |
| ⑤ 自我进化 | 历史研究结论沉淀为可复用知识 | （因子卡片 CSV 库即雏形） |

**命题方给的"建议"技术指标**（注意：命题原文写的是"建议达到"，且明确说"不以回测收益作为唯一价值证明"）：

> 年化≥10%、超额≥5%、夏普≥1.0、IR≥0.6、回撤≤15%、胜率≥52%、盈亏比≥1.3；
> 复现成功率≥90%、因子序列相关性≥0.9、证据链可追溯≥95% 等。

## 二、我们实际实现了什么（诚实的核心结论）

我们没追求"凑出一个漂亮的回测数字"，而是走了一条**可答辩、可复现**的路。用 13 只 A 股 ETF（10 股票 + 债券/货币/黄金）跑了全流程，得出几个**有据可查的发现**：

1. **反转因子、波动率因子有效**（IC≈0.08）：A 股 ETF 短期"反转主导"，追涨（动量）会亏，反向会赚。
2. **情绪因子是"反向指标"**（盘中约 -0.06、盘后约 -0.12）：新闻情绪越高涨 → 未来收益越低（情绪过热=利好出尽）。正确用法是**风控/过滤**，不是正向追涨。
3. **大盘聚焦情绪反而弱化**（|IC| 0.09→0.02）：说明情绪的反向信号来自"全市场情绪过热"，聚焦大盘新闻反而稀释了它。
4. **Jegadeesh-Titman 动量在 A 股 ETF 不可复现**（60 日窗口 -4.4%、120 日 -19.4%）：验证了研报复现的价值——结论有市场迁移性边界。
5. **多算法日频方向预测 AUC≈0.5**：诚实说明"单一价量+情绪特征在日频上没有稳定预测力"，但情绪因子在树模型特征重要性里排第 2，佐证它是"有效非线性特征、非线性收益因子"。
6. **压力测试**：载体策略在 3 类压力情景下回撤中位从 -12.8% 扩到 -15%~-19%，未出现极端塌陷。

> 一句话总结：**我们诚实证明了"单标的日频择时无解"，但"多标的轮动 + 风控优先 + 情绪因子过滤"能把基准 -45% 的回撤压到 -17% 左右（扣成本后），并把'发现过拟合'这件事本身做成了系统的核心能力。**

## 五、专业术语表（零基础版）

### 收益/风险指标
- **年化收益**：把一段时间收益折算成"一年能赚多少%"，方便横向比较。
- **波动率**：价格上下波动的幅度，越大越"颠簸"（风险高）。
- **夏普比率（Sharpe）**：每承担 1 单位风险，能多赚多少超额收益。>1 算好，0.28 是基准水平。
- **最大回撤（Max Drawdown）**：从最高点跌到最低点的最大跌幅。比如基准沪深300 是 -45%，就是"最惨时腰斩近半"。
- **超额收益（Excess Return）**：策略收益 − 基准收益。比"躺平持有沪深300"多赚的部分。
- **信息比率（IR）**：超额收益的稳定性（超额年化 ÷ 跟踪误差）。衡量"跑赢基准的能力是否稳定"。
- **胜率**：赚钱的天数（或交易）占比。>50% 表示多数时候是赚的。
- **盈亏比**：平均一次盈利 ÷ 平均一次亏损。>1 表示"赚一次够亏好几次"。

### 因子（Factor）相关
- **因子**：一个能用来预测未来收益的特征，比如"过去20日涨幅"（动量因子）、"新闻情绪"（情绪因子）。
- **因子卡片（Factor Card）**：一张标准化的因子说明书，记录定义、公式、IC、单调性、失效条件等。
- **IC（Information Coefficient）**：因子值和未来收益的相关系数，衡量因子预测力。绝对值越大越有用，正负号表方向。
- **ICIR**：IC 的稳定性 = IC 均值 ÷ IC 标准差。越高说明因子预测力越稳定。
- **单调性**：把因子从低到高分 5 组，未来收益是否单调递增/递减。单调=好因子。
- **衰减（Decay）**：因子预测力随持有期（1/5/10/20 日）变长而衰减的速度。
- **冗余**：两个因子高度相关（|corr|>0.6），只留一个即可。
- **动量因子**：赌"过去涨得多的，未来继续涨"。
- **反转因子**：赌"过去涨得多的，接下来会回落"（A 股短期更像这个）。
- **情绪因子**：把新闻情感（FinBERT 打分）聚合成的指标，属"另类因子"。

### 方法论术语
- **研报复现（Report Reproduction）**：拿一篇券商/学术研报，用自己数据重跑一遍它的因子/策略，看结论能否复现。
- **未来函数（Look-ahead Bias）**：用了"当时还不知道的信息"回测，导致结果虚高。是量化最大的坑，本项目所有回测都做了"t 日信号 → t+1 日执行"来杜绝。
- **过拟合（Overfitting）**：在历史数据上调参调到很好看，但未来失效。
- **样本外（Out-of-sample）**：训练/调参时间范围之外的数据，用来检验是否过拟合。
- **Walk-forward**：滚动推进的样本外验证，比单次切分更严格。
- **压力测试（Stress Test）**：模拟极端行情（暴跌/高波动/流动性枯竭），看策略会不会崩。
- **择时（Timing）**：选买卖时点。
- **轮动（Rotation）**：在不同标的（股票/债券/黄金/现金）之间切换持仓。
- **ETF**：交易所交易的指数基金，可像股票一样买卖，510300 就是"沪深300ETF"。
